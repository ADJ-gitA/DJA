Versions complètes

DJA garde les listes Deezer et joue chaque titre en entier grâce au lecteur officiel YouTube. Il faut pour cela une clé API YouTube (gratuite).

Comment obtenir une clé (5 min)
  1. Va sur console.cloud.google.com et connecte-toi avec ton compte Google.
  2. Crée un projet (ex. « DJA »).
  3. Menu API et services → Bibliothèque, cherche YouTube Data API v3 et clique sur Activer.
  4. API et services → Identifiants → Créer des identifiants → Clé API.
  5. Conseillé : dans Restrictions de l'API, limite la clé à « YouTube Data API v3 ».
  6. Copie la clé et colle-la ci-dessus. À refaire une fois sur chaque appareil (Mac, téléphone).

Limite gratuite : environ 100 nouveaux titres trouvés par jour. Les titres déjà trouvés sont mémorisés et ne comptent plus.
